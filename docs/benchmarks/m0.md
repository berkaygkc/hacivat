### B3 measurement notes
- B3 latency is app-side: it runs from key-handler entry (`LatencyProbe::mark_input`) to the frame that shows the edit (or paints the popup) being handed to the compositor (after `Window::draw` + `present`). It excludes OS input delivery, GPU execution and display scan-out.
- Keystrokes are replayed at 60 Hz through `Window::dispatch_keystroke` on `target/fixtures/b3-50k.sql` (50,000 lines plus one 100,000-char line); every run reported `inactive_keys=0` (window kept in front).
- `b3-completion` (build 04705ea): display 240 Hz (external 5120×1440 main display), Apple M4 Pro, 48 GB.
- `b3-typing-long-line` (build 04705ea): display 240 Hz (external 5120×1440 main display), Apple M4 Pro, 48 GB.
- `b3-typing` (build 04705ea): display 240 Hz (external 5120×1440 main display), Apple M4 Pro, 48 GB.
