# Names only, hand-curated from the MySQL 8.0/8.4 reference manual's function index and the
# MariaDB knowledge base's function list. Never from `mysql.help_*` (GPL content). The catalog
# read (`hacivat-exec/tests/gen_fn_catalog.rs`) prepares `SELECT <name>()` on every MySQL and
# MariaDB line (prepare only, nothing runs) and keeps a name for an engine where the server
# knows it; the names then land in `data/{mysql,mariadb}/allow.toml` as `source = "manual-index"`
# rows for review. One name per line; `#` starts a comment.
