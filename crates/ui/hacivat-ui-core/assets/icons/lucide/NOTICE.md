Lucide icons v0.460.0 (ISC, see LICENSE). Only the icons the harman mock and the M1 app shell use are bundled (`ICONS` in `src/assets.rs`).
Source: the `lucide-static@0.460.0` package; the license comment header and the `class` attribute are dropped.
Modification: `stroke-width="2"` rewritten to `1.6` to match the mock (`lucide.createIcons({ attrs: { "stroke-width": 1.6 } })`).

## m2a-t01-icons

The M2a connection icons, from the same package with the same modifications: `lock-open`, `rotate-cw`, `clipboard-paste`, `plug`, `unplug`, `pencil`, `external-link`, `route`, `circle-alert`, `circle-x`, `folder-open`, `file-key`. M2a also draws the already bundled `database`, `file-code-2`, `copy`, `trash-2` and `undo-2`.

## m2b-t24-shots

The M2b icons, from the same package with the same modifications: `file-up`, `arrow-right` and `fingerprint` (fix round 1). M2b also draws the already bundled `key-round`.

## m3a-t01b-seams

The M3a query icons (`design/m3a-query/NOTES.md`, "Icons"), from the same package with the same modifications: `scroll-text` (the Output tab), `skip-forward` (Skipped), `arrow-down-to-line` (Scroll to end), `eraser` (Clear), `clipboard-x` (clipboard unavailable), `ban` (Cancelled) and `copy-check` (Copied).
